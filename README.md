# 🔋 MSGBOT

---

## 📦 Быстрая установка

```bash
git clone https://github.com/4539617/msgbot.git /opt/msgbot
cd /opt/msgbot
bash install.sh
```

---

### 🤖 Возможности бота

**Для клиентов:**
- Выбор типа транспорта: самокат, велосипед, мопед
- Выбор причины поломки: 💧 вода, ❌ не включается, ⚡ переразряд, 🔌 не заряжается, 🔧 замена BMS
- Текстовое описание проблемы
- Прикрепление до 5 фото и/или видео
- Подтверждение перед отправкой
- Уведомления об изменении статуса заявки

**Для администраторов:**
- Мгновенное уведомление о новой заявке
- Ответ клиенту прямо из Telegram
- Смена статуса: принять в работу / закрыть
- Команды: `/list`, `/new`, `/inwork`, `/stats`
